MitID Auto Authenticator

MitID admin credential

The OAuth client credential for the MitID pre-production admin API, used to add Identities. Approving works without it. It is not provided with the extension. It is stored in this browser profile only.

Import / export

One Identity per line, as in the console app's mitid_users.txt: userId,identityId,authenticatorId. Import adds the lines whose user ID isn't already in the list.
